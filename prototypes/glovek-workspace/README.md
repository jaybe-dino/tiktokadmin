# Glovek Workspace (로컬 전용 프로토타입)

가상 예시 데이터로 만든 **로컬 우선(local-first) CRM 작업공간**입니다.
브라우저 저장소에만 쓰고, 실제 운영 어드민·API·Google Sheet·메일과 **연결되지 않습니다.**

## 실행

```bash
cd prototypes/glovek-workspace
python3 -m http.server 8788
# → http://127.0.0.1:8788/index.html
```

설치·빌드·API 키가 필요 없습니다. 외부 폰트·아이콘·CDN 을 받지 않습니다.
`file://` 로 직접 열어도 동작합니다(일반 `<script>` 만 쓰고 ES 모듈을 쓰지 않습니다).

## 화면

| 화면 | 하는 일 |
|---|---|
| 유입·전체 DB | 시작 화면. 엑셀처럼 보고 셀을 더블클릭해 바로 고칩니다. 탭(전체/회사·브랜드/크리에이터), 검색, 필터 6종, 정렬, 페이지, 다중선택, 일괄 담당자·등급, 열 선택, CSV 내보내기 |
| 우측 상세 | 기본/연락처/매출 탭, 커뮤니케이션 타임라인, 메모, 연결된 기회·할 일, 변경 이력 |
| 영업 보드 | 업체 DB 와 별개인 영업 기회. 포인터 드래그 + 키보드 이동, 단계 게이트, 되돌리기, 종료(수주/보류/실패) |
| 내 할 일 | 지남/오늘/예정/완료, 업체·기회 연결, 완료·재개 |
| 커뮤니케이션 | 수기 기록(수신/발신 × 메일/전화/미팅/채팅), 검색·필터, 상세 타임라인 반영 |
| 가져오기·연결 | CSV·XLSX 가져오기(매핑·미리보기·검증·업서트·중복 후보·오류 내보내기), 가져오기 이력, 연결 상태(미연결) |
| 변경 이력 | 작업·대상 필터, before/after, CSV 내보내기 |
| 설정 | 구성원, 기본 화면·밀도, 연결 설정 초안, 백업 내보내기/복원/초기화 |

## 데이터

- 저장 키: `glovek.workspace` (localStorage), 스키마 버전 3
- 쓰기는 트랜잭션입니다. 저장이 실패하면(용량 초과 등) 화면 경고를 띄우고 **저장된 내용을 깨뜨리지 않습니다.**
- 모든 쓰기는 변경 이력(before/after·시각·행위자)으로 남습니다.
- 예시 데이터는 회사·브랜드 35건 + 크리에이터 12건 = **47건**이며 전부 가상입니다.
  표시되는 건수는 예시 데이터의 건수이지 실제 운영 원장 규모가 아닙니다.

## 지키는 것

- 사용자·파일에서 온 문자열은 `textContent` 로만 넣습니다(XSS 방지).
- 링크는 `http(s)` 만 통과시키고 `javascript:`·`data:`·자격증명 포함 주소는 차단합니다. 외부 링크는 `rel="noopener noreferrer"`.
- CSV 내보내기는 수식 주입을 막습니다(`=`·`+`·`-`·`@` 앞에 `'`).
- 네트워크 호출이 없습니다. 자동 새로고침 타이머·가짜 카운터가 없습니다.
- "미확인" 과 "0" 을 구분합니다.
- 고객사 연매출과 우리 계약 금액을 같은 칸에 섞지 않습니다.

## 한계 (정직하게)

- **메일·운영 API·Google Sheet 연동은 연결되어 있지 않습니다.** 설정 초안은 로컬에만 저장되고,
  연결 테스트는 "백엔드가 없다" 는 사실을 그대로 보고합니다.
- 로그인·권한은 **없습니다.** 설정의 구성원·역할은 예시 담당자 목록이며 서버 인증이 아닙니다.
- XLSX 는 읽기 전용(첫 시트)이며 `DecompressionStream` 을 쓰는 최신 브라우저에서 동작합니다.
