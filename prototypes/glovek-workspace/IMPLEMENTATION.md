Safe transactional updates, clear storage failure warning, backup export/restore with validation, reset only after explicit confirm. Dates relative to today. Never show sample quantities as the real 70k database.

## Safety and quality
Use textContent or escaped text for all user/file imported strings; no XSS via names, notes, URLs, CSV cells. Block javascript/data unsafe link schemes, use rel noopener target blank. Guard CSV formula injection on export. Event listeners are stable across rerenders, modal focus management and Escape. Buttons work without host sandbox. App starts without remote network. No production requests, mutations or external sends. Fail safely for malformed backups and invalid files, preserve store if storage full, validation never silently writes invalid amount/dates.
