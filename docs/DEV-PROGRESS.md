- 공개 렌더러 `/proposal/[token]` — 핑크 9섹션 데크(표지·핵심SKU·요약+상당구성가치·로드맵·6개월/1년 KPI·별도제안·레퍼런스·E.O.D.). 발행본만 공개(`?preview=1` 관리자 미리보기), 인쇄/PDF 대응.

### 마케팅
- `/mkt` — 개별 프로젝트 파이프라인(카드 클릭 상세 편집·제안서 연결 표시) / 루틴 운영대행 / 마케팅 제안서(작성 시 프로젝트 자동 생성·상태 동기화) / 브랜드 매핑.
