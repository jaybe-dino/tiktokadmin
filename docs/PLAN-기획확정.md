# GloveK 어드민 · 파트별 기획 확정 (운영자 질의 확정본)

> 운영자(대표) 질의응답으로 확정한 파트별 정책. **코드는 이 문서를 따른다** — 변경 시 이 문서부터 갱신.

## 1. 대시보드
- **홈 개인화**: [내 담당만 ↔ 전체] 토글(승인대기·오늘미팅에 적용, 담당 브랜드 있으면 기본=내 담당만)
- **승인 대기 카드**: 발송류(메일·리마인더)는 홈에서 바로 승인·발송 / 결재(드랍·환불·정산확정·할인)는 결재함에서만
- **KPI 4타일**: 전체 브랜드(원장) · 운영 중(멀티몰+온보딩) · SLA 위반 · 이번주 세미나→미팅 전환%
- **역할 분담**: 홈=전사 요약+승인 / 워크큐=내 할일 상세(우선순위 정렬)
- **보드**: 전 직원 카드 이동 가능(게이트 검증) + stage_history.actor 이력 기록 / 카드에 등급·메모·담당·SLA·경과일 + **플랜·기한** 표시
- **SLA 사다리**: T1 매일 담당 DM → +2일 T2 파트장 채널 → +5일 T3 대표 적색목록 (기한은 설정의 SLA 정책) / 채널 = **Slack + 이메일**

## 2. 고객
- **리드 배정**: 수동 수락(미배정 유입 → 담당 수락, 미수락은 SLA 사다리 압박)
- **등급 5대 지표**: 담당자가 보정(충족/미충족/미입력 3상태), 미입력=**"입력 필요"** 표시, **운영(live) 전이 전 5개 전부 입력 필수(게이트)**. 판정 로직은 gradeFromChecks 단일 원천
- **중복**: email→phone→사업자번호→이름+URL 자동 병합, 애매하면 중복정리에서 수동
- **lead_group**: 대량 발송 타깃 용도(발송센터 그룹 선택)

## 3. 영업
- **할인 결재**: 견적은 computeQuote 단일 원천(수기 수정 불가) · 추가 할인 **20% 이하 자동통과, 초과 시 파트장 결재**(approval_requests kind=discount, 승인 전 발송 잠금)
- **노쇼**: 감지 시 재예약 제안 메일 **초안 자동 생성**(담당 승인 후 발송) + 2회 노쇼 시 noshow_repeat 알림
- **계약**: 전자서명 미도입 — 서명본 파일 업로드 + 상태 전환 유지
- **결제 확인**: 자동 전진 금지 — payment_confirmed **알림만**, 전진은 담당이 게이트 경유 수동

## 4. 마케팅·커뮤니케이션
- **대량 발송**: **담당 재량**(별도 결재 없음) — 단 수신동의 게이트는 대상 산정에서 항상 적용
- **윈백**: 세그먼트·초안은 에이전트가 자동 준비, **발송은 사람 승인** (수신동의자 한정)
- **공용 메일함 이관**: 현재 단계 담당자 자동 전달 + 메일함에서 수동 이관
- **AI 인바운드 회신**: 초안까지만 자동, **담당 승인 후 발송**

## 5. 온보딩·제품 (현행 확정)
- **서류 리마인더**: 매일 에이전트 초안 생성 → 담당 승인 발송
- **인증 관리**: 온보딩 담당 책임 + 만료 30일 전 cert_watch 알림

## 6. 운영·정산 (현행 확정)
- **사이클 경보**: 매월 15일 이후 이행률 50% 미만 시 알림
- **정산 확정**: 월말 자동 draft(이상치 플래그) → 정산 담당 검토 → lead/exec 확정 → 포털 게시·이의제기 처리
