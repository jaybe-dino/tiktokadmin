## 1. 코드로 아직 개발 안 된 것 (내가 개발 가능)

### 1-A. AI 로드맵 (aiText 재사용 · 키 넣으면 동작) — ⏳ 이번에 워크플로우로 진행
- **QnA AI 답변 추천** — 미답 질문에 지식베이스 유사 QnA 기반 답변 초안 추천
- **제안서 AI 커스텀 문구** — 브랜드 맥락으로 제안서 소개/설득 문구 생성
- **인증 필요서류 AI 가이드** — 제품·국가별 필요 인증/서류 체크리스트 초안
- **사이클 종료 월간 리포트 AI 초안** — 운영 사이클 마감 시 성과 요약 초안
- **화면 컨텍스트 AI 패널** — 브랜드360 우측 "AI 도우미"(질의·다음액션 제안)

### 1-B. 결제·정산 심화
- **PG 웹훅 실연동** — glovek 멀티몰 결제 웹훅→pay_status 자동 전진(ingest payment 경로는 있음, 실 PG 검증 필요)
- **정산 실계산** — lives.gmv 합산→fee·정산액 자동 산출(현재 draft 골격)
- **세금계산서 발행** 연동(익월 15일 지급 플로우)

### 1-C. 성능(로딩)
- **페이지별 Suspense 스트리밍** — 현재는 route-level 스켈레톤(loading.tsx)까지. 무거운 섹션은 로드되는 대로 표시
- **핫경로 인덱스 추가** 마이그레이션 + 목록 화면 부분 캐시(revalidate)

### 1-D. 기타
- **낙관적 잠금**(brands.version) — 동시 편집 충돌 방지
- **모바일 반응형** 세부 · 접근성(a11y) 보강
- **자동화 테스트**(단위/E2E) 커버리지

## 2. 운영자 활성화 (개발 아님 · env/설정) ★ 실동작에 필수

| 항목 | env / 작업 | 효과 |
|---|---|---|
| **로딩 최대 레버** | Neon **pooled** 연결(`-pooler`) + Vercel 동일 리전 | 콜드스타트·핸드셰이크 지연 대폭↓ |
| **문자 실발송** | `ALIGO_TEST_MODE=N` + **Fixie 고정IP**(`ALIGO_PROXY_URL`) | 실제 SMS 발송(현재 테스트모드/IP인증) |
| **메일 실발송** | `RESEND_API_KEY`·`RESEND_FROM`(도메인 인증) | 초안함·안내·전달 메일 발송 |
| **메일 수집** | `GOOGLE_SA_KEY_JSON`(도메인위임) | 공용 메일함 수집→담당자 전달·AI 회신 |
| **미팅 자동화** | `ZOOM_*`(S2S+웹훅) + `OPENAI/GROQ`(전사) | 녹화→회의록→팔로업 |
| **AI 활성** | `ANTHROPIC_API_KEY` | AI 회신·요약·에이전트·로드맵 |
| **Slack** | `SLACK_BOT_TOKEN`·서명·채널 | 알림·`/ask`·버튼 |
| **로그인** | `ADMIN_BOOTSTRAP_PASSWORD` + 부트스트랩 1회 | 초기 계정 비밀번호 |
